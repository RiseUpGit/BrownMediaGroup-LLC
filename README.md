## What We Do

- **PC Repair & Tech Content** — YouTube channel focused on honest repairs, unboxings, and build guides
- **Software Development** — Desktop applications, AI tooling, and open-source utilities
- **Media Production** — CapCut editing, YouTube long-form and shorts, b-roll production
- **AI & Automation** — Local-first AI workflows, model management, agent tooling

## Our Stack

We build with practical, proven technology:

- **Desktop apps:** Tauri v2 + Rust backend + SQLite
- **AI/ML:** Ollama local inference, GGUF model management, Qwen/Gemma/Nous model families
- **Media:** CapCut, FFmpeg, iPhone MOV assembly pipeline
- **Deploy:** Netlify for static sites, MSI packaging for Windows desktop
- **Dev environment:** RustRover, PyCharm, Hermes Agent, Obsidian
